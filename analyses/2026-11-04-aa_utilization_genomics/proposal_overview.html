The question

For each of the 20 amino acids, which strains carry an enzyme that takes the nitrogen off, and how does that differ between clades and from Synechococcus? A standalone, descriptive map: no hypothesis, no formal statistics. Transporters (uptake) are set aside for now.

Comparison group. The closest relative, with the same annotations. Asks "how does Prochlorococcus compare?"

Not used to judge the method: looking similar could be real biology. Its genomes are larger, so gene count is shown beside every strain.

Two ways to take the nitrogen off

Release as ammonium

amino acid→deaminase · lyase · dehydrogenase · amidase→NH₄⁺

Some go through several steps first, e.g. arginine → agmatine → urea → NH₄⁺. Those are scored as steps present (k of n).

Transfer to glutamate

amino acid+2-oxoglutarate→aminotransferase→glutamate

Many aminotransferases also build amino acids, so most fall in "shared".

Each strain × amino acid gets one call

dedicated: has a breakdown-only enzyme (e.g. glutamate dehydrogenase, arginase) shared only: only enzymes also used to build amino acids (e.g. ilvE) none found

Enzymes come from a catalogue you approve (KEGG IDs, checked against KEGG). Genes are matched by enzyme ID, never by gene name.

How we will know the method works

Must be found

  • glnA (glutamine synthetase) in all 45 strains: tests the gene-matching
  • 2–3 aminotransferases that amino-acid building needs (e.g. ilvE, hisC), in every complete genome

Must come out empty

  • A strain with only "shared" enzymes is never called "dedicated"
  • One breakdown-only enzyme, named in advance as expected absent in all 45 strains

Findings, not failures

  • All strains look the same
  • Only "shared" enzymes in Prochlorococcus
  • Most amino acids: none found

Caveats that travel with every result

  • Enzyme ≠ using outside amino acids. These enzymes also act on amino acids made inside the cell. With uptake set aside, we cannot say a strain uses external amino acids as an N source.
  • Annotation ≠ function. An enzyme-family match does not prove activity or substrate.
  • "None found" may mean "not sequenced". NCBI assembly status is used to flag incomplete genomes.
  • No heterotroph check. "No breakdown-only enzyme found" is reported with that limit.
  • Small clades (HLIII, HLIV, LLIII) cannot stand for their clade.
  • Early look: MED4 results were seen before the rules were locked. This is recorded in the plan notebook.
